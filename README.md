# Klio - EDB Postgres Backup & Recovery Manager for CloudNativePG

The EDB Postgres Backup and Recovery Manager for CloudNativePG
is designed to set a new benchmark in enterprise-grade backup
and recovery for PostgreSQL databases on Kubernetes, specifically.

The name *Klio* is inspired by Clio, the muse of history, symbolizing the preservation and recovery
of past events, which resonates with database backup

Documentation: https://enterprisedb.github.io/klio
